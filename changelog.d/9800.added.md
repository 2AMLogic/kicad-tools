- **`kct render` binds its artifacts to the rendered PCB** (Issue #9800). A
  complete run writes `renders/render-provenance.json` recording the PCB's
  SHA-256 and each image's SHA-256 (deterministic, no timestamps); an
  incomplete run removes any stale sidecar. Board 02's release publisher
  gained the matching changed-artwork branch: when the checked board's
  printed artwork differs from the previous package's archived PCB, the
  fresh renders ship only with that binding, which also travels inside the
  package. A missing, stale or tampered binding refuses the run and leaves
  the previous ready package in place.
