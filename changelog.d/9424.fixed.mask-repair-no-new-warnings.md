- **`kct fix-drc --only mask-copper --no-new-warnings` refuses to trade an error for a warning** (Issue #9424). With the flag, a mask repair is reverted when its re-check shows a non-mask warning the board did not have (`pour_slot`, `redundant_copper_*`) or a mask warning on a pair the board did not flag; a finding that only drops from error to warning still counts as repaired. The default is unchanged. The Board 05 unattended gate now runs the guarded repair before grading.
