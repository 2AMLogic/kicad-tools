- **Datasheet extraction no longer reads a bare `P<digits>` token as a measured lead pitch** (Issue #10328). In a package
  table row, a stray `P48`, `(P48)` or `p 113` reached `PackageInfo.pitch` as a measured value with confidence 1.0. The
  single-letter `P` form now needs a unit (`P0.8mm`, `P50 mil`) or an assignment separator (`P=0.8`); the word `pitch`
  and `e =` assignments are unchanged. A stray token before an explicit `pitch = 0.80` no longer masks that measurement,
  and a row with only the stray token falls back to the family's inferred pitch at reduced confidence.
