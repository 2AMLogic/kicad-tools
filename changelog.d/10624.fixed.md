- **Design report front matter stays valid YAML when the PCB filename contains a quote** (Issue #10624). The `title`, `subtitle` and `author` scalars in `report.md` are now escaped with the same filter as the revision line, so a board named `ctl "bench".kicad_pcb` no longer produces front matter that PyYAML and Pandoc reject, and the HTML/WeasyPrint cover shows the exact project name.
