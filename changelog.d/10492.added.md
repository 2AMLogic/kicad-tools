- **`kct export --verify-reviewed-copper` publishes only copper that was
  reviewed** (Issue #10492). The opt-in plots the saved board natively before
  any rule is written or any zone refilled, prepares the manufacturer rules,
  refill, silk pass and artwork on a private working copy, and compares every
  copper layer of the staged Gerber archive with that reference as geometry
  before anything is published. Timestamps, X2 metadata and a polygon's
  starting vertex never read as a change; copper that moved with its area
  intact does. Changed copper withholds the package with a non-zero exit and a
  per-layer added/removed mm² report, leaves an earlier package and the
  checked-out board, project and rule files exactly as they were, and copies
  the proposed board, rules and Gerbers to a `<output>-reviewed-copper/`
  directory beside the package for the designer to inspect and adopt. A
  missing, ambiguous or unreadable copper layer, or no native plotter, withholds
  it the same way. Identical copper publishes the normal package, and
  `manifest.json` and `README.txt` name the reviewed PCB by file name and
  SHA-256 with each reference plot digest and the area tolerance. Inner layers
  are matched by their X2 file function, so renamed copper layers verify. The
  default export is unchanged.
