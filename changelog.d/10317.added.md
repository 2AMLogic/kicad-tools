- **`kct creepage --exceptions` waives one reviewed pad pair, not the whole footprint**
  (Issue #10317). A JSON sidecar of per-(footprint, pad pair, metric) exceptions
  complements `--waive-same-footprint`: each entry names one component, one
  unordered pair of its pads, one metric (`creepage` or `clearance`) and a
  non-blank reason. For affected net pairs the census reports every pad pair of
  every package sharing the two nets as its own row (`R1.1-2` in the table;
  `footprint`, `pads`, `exception` and the per-row `gate_pass` in JSON)
  instead of the collapsed binding minimum, so waiving R1 leaves a second
  package on the same nets, a different pad pair, the other metric on the same
  pads and every board-level approach failing independently -- including when
  gaps tie or the waived pair is the closest. Raw measurements, bounds and
  verdicts stay in the JSON (`passed` is never relaxed), the exit code follows
  the waiver-aware gate, and the broad waiver remains a separate explicit
  opt-in. An invalid, ambiguous or unmatched selector is an error and can never
  waive a finding; `kct audit`'s waiver-blind gate is unchanged.
