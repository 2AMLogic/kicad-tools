- **`MaskCopperRepairer` gates aligned-pad bridge candidates on `is_45_aligned`** (Issue #10601). Near-aligned same-net pad pairs whose centre-to-centre vector exceeds `ANGLE_TOL_DEG` (`0.01°`) are now declined early as `pad_centres_not_aligned` before clearance evaluation or copper mutation, so library callers never write an off-angle bridge segment.
