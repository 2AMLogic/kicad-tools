- **`kct readiness` resolves a project-declared output directory** (Issue
  #10106). A project-local kicad-tools TOML `[readiness]` section with
  `output_root = "output"` authorizes publishing the bundle
  (`output/manufacturing/`), outer ZIP (`output/manufacturing.zip`), generated
  receipt (`output/readiness.json`), evidence (`output/readiness/`) and
  verification/attempt diagnostics under that sibling root for boards that
  live in `kicad/`. The declaration establishes the project boundary, receipts
  key their inputs against the declaring project (so a moved project still
  verifies), and an explicit `--output` must stay inside the declared root.
  Unsafe declarations — a root outside the project, the board directory
  itself, or symlinks crossing either boundary — refuse before any file is
  read or written; without a declaration the board-local destinations and
  `--output` refusals are unchanged, and a user-wide config never authorizes
  a sibling.
  A save through an already-open board or artifact file survives a refused
  regeneration, including when the project is on FAT32.
