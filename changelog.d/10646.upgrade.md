- **`kct readiness` can newly exit 2 on a host without the offline parts catalog** (Issue #10646). An assembly package whose `bom_lcsc_stock` record says the catalog was `missing` or `unreadable` — including one regenerated on a catalog-less worker — no longer publishes or verifies as `ready`. Run `kct parts sync-catalog` on the generating host, then `kct readiness <board> --generate`; the catalog lands under `$XDG_CACHE_HOME` (default `~/.cache/kicad-tools/jlcparts.sqlite3`), so a session that redirects `XDG_CACHE_HOME` does not see a catalog downloaded elsewhere.
