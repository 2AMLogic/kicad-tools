- **`kct optimize-placement` now optimizes a different objective on multi-sheet boards** (Issue #10146). The new `group_cohesion` and `group_order` weights default to `1.0`, so a board whose schematic is discoverable gets sheet-grouping terms and one extra kicad-cli netlist export per run. To restore the previous objective (and skip the export), pass `--weights '{"group_cohesion": 0, "group_order": 0}'`.
