- **`kct sch re-annotate --check` reports reference order disagreements** (Issue #10132). New read-only `--check` flag lists, per prefix, the parts whose current reference number order differs from the order `re-annotate` would assign (schematic position order) with their old->new mapping, honours `--prefix`/`--per-sheet`, supports `--format json`, and exits 1 when any part disagrees — gaps in numbering alone are not flagged. Files are never modified under `--check`.
