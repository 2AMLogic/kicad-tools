- **`kct export` reports broken footprint-to-symbol links in the editable-project handoff** (Issue #10109). The project-archive step now compares the packaged board's footprint `(path ...)` tokens against the schematic hierarchy's symbol instance paths and warns, by reference, about missing, duplicated and stale links plus missing or inconsistent footprint library identifiers — read-only, never blocking. Board-only footprints, `on_board no` symbols, DNP parts and multi-unit symbols are handled, and the package README gains an "Editing handoff" section when defects are found.
