- **Untented via mask openings follow the board's `pad_to_mask_clearance`** (Issue #10384). `silk_over_copper` and the silk reference-placement keepouts sized an untented via's opening with the manufacturer profile's margin while pads used the board's declared clearance. Both now resolve one margin, which is the opening KiCad plots: on KiCad 10.0.6 an untented via flashes its size plus twice `pad_to_mask_clearance`. A via has no per-via margin override, so the board's clearance applies to every untented via, and the profile's margin is used only when the board declares none.
