- **`kct route-link` refuses a `(chamfer ...)` token on a pad whose shape is not `roundrect`** (Issue #10720). KiCad reads such a pad as a chamfered rectangle whatever shape the file declares, so the plain outline of the declared shape claimed copper KiCad cuts away. The named-pad router now refuses it, as it already refused an unusable chamfer on a `roundrect` pad, and both routing models read the pad the same way.
