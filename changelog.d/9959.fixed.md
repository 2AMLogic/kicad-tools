- **A DRC retry can no longer inherit the rejected attempt's report** (Issue #9959). `run_kicad_drc_command` now clears the report path named by the argv (`--output`/`-o`, separate or joined) immediately before **every** launch — first attempt and flag-less retry alike — so a retry that writes nothing is judged as "no report" instead of reading the previous attempt's file as a clean result. The reset moved out of the callers: `_run_drc_once` and the starved-thermal `_kicad_drc_report` argv builder no longer unlink anything, making argv inspection side-effect-free. Native connectivity reconciliation now reads its report from a fresh path in a private directory and validates it: on an accepted exit code (0 or 5) with a missing, empty, malformed or incomplete report, it emits a `RuntimeWarning` naming the cause and keeps the internal connectivity findings instead of silently substituting an empty native result. A complete fresh report with zero relationships still yields zero native relationships.
