- **`kct check` ignores a reinforcement sidecar entry that is not an object** (Issue #10398).
  `load_wires_if_present` returns only the JSON objects in the `wires` list of
  `<board>.reinforcement.json`, in file order with their fields untouched, so a hand-edited
  `null` or scalar beside the records no longer reaches the validation rules; a list with no
  objects reads as no wires, and an absent or unreadable sidecar still reads as none. Nothing
  on disk is changed: the lower-level `load_wires` keeps returning every entry for the writers.
