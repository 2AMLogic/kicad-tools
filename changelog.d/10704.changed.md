- **`kct check` words a multi-way `sharp_trace_corner` as `N-way junction`, no longer `N-segment junction`** (Issue #10704). The count is the number of track directions leaving the vertex (Issue #10675), so a branch into the middle of an unsplit track reported `3-segment junction` where the board holds two segments; `N-way` says what is counted. Rule IDs, `corner_class` values and waiver keys are unchanged; only the message text differs.
