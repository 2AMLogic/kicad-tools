- **`kct sch re-annotate --pcb <board.kicad_pcb>`** (Issue #10145). New opt-in
  flag that carries the schematic renumbering to the board in one step:
  footprint `Reference` values (and their silkscreen text) are renamed with the
  same collision-safe plan used by `pcb reannotate`. `--dry-run` previews both
  files, `--backup` backs up the board too, and `--format json` gains a `pcb`
  section (path, renamed count, warnings). Unannotated (`R?`) entries and old
  refs absent from the board are skipped with warnings. With `--per-sheet`,
  a duplicate footprint reference across sheets stops the command before it writes either file.
