- **Strict gates now pass on DRC reports that carry only informational
  findings** (Issue #10650). `kct drc --strict`, `kct drc --mfr --strict` and
  `kct stitch`'s post-stitch DRC exit 0 for such a report when their other
  gates pass, and export's DRC preflight reads OK instead of WARN, so a
  pipeline that relied on exit 2 or `WARN` from an info-only report no longer
  gets it. In the `kct drc --format json` `summary` object the informational
  rows are in `infos`, which is present only when the count is nonzero, like
  `waived`. A waived finding likewise counts as neither an error nor a warning
  in `DRCReport.warning_count`, matching what `kct drc` already printed.
  Board 04's refreshed manufacturing manifest counts its four pour-slot
  warnings. Other committed manifests retain their previous totals until
  regeneration. For example, Board 03's recorded total of 309 includes
  296 warnings and 13 informational findings.
