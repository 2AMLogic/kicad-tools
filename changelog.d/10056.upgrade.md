- **`kct export` now leaves a recovery directory beside the board after each successful checked rewrite or rollback of a published PCB** (Issue #10056). If you run exports inside a tracked tree, expect new untracked `.<board>.kicad_pcb.recovery-*` directories (gitignored for `boards/` in this repo; add the pattern to your own `.gitignore` if needed). Nothing is deleted automatically -- run `kct clean <project>.kicad_pro --force` to remove retained copies once you no longer need them.
