- **`KCT_JLCPARTS_CATALOG` pins the location of the offline jlcparts catalog** (Issue
  #10655). Every reader and writer of the catalog (`kct readiness`, `kct export
  --strict-preflight`, `kct parts alternatives`, `kct parts sync-catalog` and the
  `LCSCClient` offline fallback) resolves it through this one variable, so a
  session whose runtime redirects `XDG_CACHE_HOME` can keep using the catalog
  already stored under `~/.cache/kicad-tools/jlcparts.sqlite3` instead of
  reporting it missing. Unset or blank keeps the default beside the parts cache;
  an explicit path argument still takes precedence. Default behaviour without the
  variable is unchanged.
