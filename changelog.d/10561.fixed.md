- **Board 03's `usb_geometry()` measures the USB common run inside its window, however KiCad splits a track** (Issue #10561). Each In2.Cu centerline is clipped to the measurement window before connectivity and coupling are measured, and contiguous collinear pieces of one width are joined, so subdividing a track no longer flips the gate between `Missing USB common run` and a passing length. The committed board now reads 4.343 mm of coupled run (was 4.071 mm); the 4.0 mm coupled, 16.0 mm branch, full-speed skew and 4.0 mm MCU-launch bounds are unchanged.
