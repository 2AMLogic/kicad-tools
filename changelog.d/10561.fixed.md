- **Board 03's `usb_geometry()` measures the USB common run inside its window, however KiCad splits a track** (Issue #10561). Each In2.Cu centerline is clipped to the measurement window before connectivity and coupling are measured, and contiguous collinear pieces of one width are joined (including slivers a few nanometres long), so subdividing a track no longer flips the gate between `Missing USB common run` and a passing length. The fix is staged at `boards/03-usb-joystick/engineering/routing_plan_10561.py` until the producer-run reissue owned by #8900 moves it into the live recipe and archive; the live `routing_plan.py` is unchanged.
