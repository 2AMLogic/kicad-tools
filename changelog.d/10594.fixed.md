- **`kct report generate` and `kct export` now use the PCB's authored title-block revision in design report headers** (Issue #10594). When no explicit snapshot `revision` override is supplied, Markdown and PDF headers show the `.kicad_pcb` `(title_block (rev ...))` value instead of defaulting to `Rev 1`, while keeping `"1"` as the fallback for unversioned boards and preserving `v1`/`v2` output directory numbering.
