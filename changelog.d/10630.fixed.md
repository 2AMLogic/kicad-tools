- **Pandoc PDF reports keep a literal backslash in the project title** (Issue #10630). `render_pdf_pandoc` now hands the `title`, `subtitle`, `author` and `date` cover scalars to Pandoc as literal `--metadata` values instead of letting it read them from the YAML block as Markdown, so a report named `Panel A\B` no longer fails in XeLaTeX (exit 43) and the PDF shows the complete title and revision. Titles containing quotes, such as `ctl "bench"`, are set from the name's own straight quotes instead of Pandoc's typographic ones.
