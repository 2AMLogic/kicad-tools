- **Named-stackup export requires the silk repair it requested** (Issue #10051). When the default silk legalisation pass cannot run — for example the board lives on a filesystem without hard-link support, which the pass's checked publication path probes for — `kct export --stackup-id` now stops with `Silk legalisation pass could not run: ...` before writing anything, instead of shipping unrepaired silk with a warning. Exports without a named stackup keep the warning-and-continue behaviour; pass `--no-silk-fix` to export the original artwork on such a filesystem.
