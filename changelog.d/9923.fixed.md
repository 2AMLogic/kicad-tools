- **`kct route`'s Python Pathfinder scores rotated foreign pads by their real shape** (Issue #9923). The world-coordinate via-placement check stored each foreign pad as its pre-rotation `(x, y, width, height)` box, so a pad turned away from the board axes under-reached toward a via placed off its long side: four pinned KiCad 10.0.6 clearance violations (conformance seeds 1/44/135/151, native gaps 0.1600-0.1933 mm against a 0.20 mm rule) were accepted on otherwise clear cells. The pad context now carries the clearance kernel's exact `KPad` (shape and rotation preserved) and the candidate via is compared with `clear`, with a board-aligned bounding box ruling out distant pads before the kernel runs. Six native-legal rotated pairs the doubled-rotation-box fix would have rejected stay accepted. The C++ backend path is unchanged (it never consumed the via foreign-pad context).
