- **`kct pcb center-on-sheet` keeps the reinforcement record in step with the board** (Issue #10250). The command now applies the same translation to the sheet-absolute anchors, leg endpoints and parallel-copy coordinates in `<board>.reinforcement.json` (written beside `-o` output, listed as `sidecar` in the JSON result, untouched on `--dry-run`), and stages the PCB and record together so a failure leaves the pair unchanged. An unreadable sidecar now fails before anything is written.
