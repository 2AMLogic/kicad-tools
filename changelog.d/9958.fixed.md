- **`kct fix-drc --only mask-copper` no longer aborts the repair batch when two nudges share a track endpoint** (Issue #9958). A pass-through nudge whose conductor an earlier move in the same plan already dragged is deferred with a `segment_end_already_moved` skip instead of stacking a second edit on the shared endpoint, and the verifier undoes grouped moves in reverse application order so overlapping edits that do get through still roll back exactly. A failed batch no longer reports `recheck_unavailable` for actions that already carry a specific disposition, so each action appears under exactly one reason in the JSON.
