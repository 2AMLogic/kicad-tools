- **`kct pcb reinforce` refuses a wire-list sidecar entry that is not an object** (Issue #10401).
  When `<board>.reinforcement.json` holds `null`, a number, a string, an array or a boolean among
  its `wires`, every pass that reads the list as records -- `--net` when it records wires,
  `--clear`, `--replace`, `--adopt`, and `--list-wires` in text or with `--net` -- exits 1 with
  `<sidecar>: wires[<i>] is <type>, not a JSON object` instead of raising a traceback, and writes
  nothing: input and output boards and sidecars keep their bytes, including the `-o` output board,
  whose sidecar `--clear` used to reach only after saving it. `--list-wires --format json` without
  `--net` still prints the file as it stands.
