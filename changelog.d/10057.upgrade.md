- **`kct route` default `--auto-layers` runs now exit 3 on a DRC-only failure** (Issue #10057). Fully connected copper whose verified post-route DRC found errors previously returned exit 0 with a `success` JSON verdict on the default path; scripts that accepted exit 0 for that case now see exit 3 and `summary.failure_reason = "post_route_drc"`. Gate on the exit code (or run `kct check <routed.kicad_pcb> --drc-only`) where a clean board is required.
