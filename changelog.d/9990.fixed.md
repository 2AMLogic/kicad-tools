- **Named-stackup export survives its own silk repair** (Issue #9990). The
  default silk legalisation pass re-saves the board in place, which made
  `kct export --stackup-id` fail with `PCB changed during manufacturing
  export` after the package files were already written. The pass now reports
  the sha256 of the bytes it wrote and the export re-binds the ordering
  record to those bytes through the same validation as at the start, so the
  record describes the repaired PCB that ships while any external edit still
  fails the change guard.
