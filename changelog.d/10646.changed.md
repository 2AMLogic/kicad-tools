- **`kct readiness` refuses procurement evidence produced without the offline parts catalog** (Issue #10646). When a package's `lcsc_stock_order` records `sources.offline_catalog` as `missing` or `unreadable`, its LCSC lookups never reached a usable catalog, so the stock check describes the host that ran the export rather than the board; `--generate` and `--verify` now exit 2 and write nothing (the way an unqualified kicad-cli is refused), naming the catalog path and `kct parts sync-catalog`. A catalog that was searched still publishes exactly as before: `hit` verifies, `miss` is an honest WARN about the part. Verification judges the recorded sources, never its own host's catalog, so catalog-backed evidence stays verifiable anywhere. Boards 00 and 01 are regenerated with catalog-backed evidence: `offline_catalog: "hit"`, `lcsc_stock_order` OK, and a `bom` check that verifies every assigned item again.
