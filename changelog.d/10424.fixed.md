Assembly BOM enrichment checks explicit schematic MPNs and resistor tolerance and power requirements before assigning catalogue parts, including cached matches. Wire solder landings no longer receive generic component suggestions. **LCSC reuse now checks each receiving reference and needs positive catalogue evidence** (Issue #10424). A shared code is accepted or refused per reference (a sibling with a tighter tolerance/power rating stays blank without evicting the cache entry its neighbour uses); a chip-resistor row needs a catalogue record that establishes its chip package, and ratings come from the structured `tolerance`/`power_rating` fields or an unambiguous "rated power" description.
