- **`kct route` declares a router class at the width the copper uses, even when the project's `Default` is wider** (Issue #10555). The DRC-constraint sidecar writer creates each router class as a clone of `Default`, and the stricter-wins merge (#7385) then could not lower it: a `Differential` class routed at 0.15 mm was declared at `Default`'s 0.20 mm. Track width is now written exactly for a class that a valid kct project stamp and the recorded `meta.kct_router_netclasses` entry prove kct created and nobody edited since. Clearance and via dimensions keep the stricter-wins merge, and a missing or stale stamp, or a same-named class kct never recorded, keeps the merge for width too, so a width you raise in KiCad survives both a re-route's sidecar regeneration and the final project write.
