- **`kct route` writes the net classes it routed with into the KiCad project** (Issue #10133). The route step now declares one `net_settings.classes` entry per router class actually used (track width, clearance floored at the project's minimum clearance, and via diameter from the router's own class map) and one exact-name `netclass_assignments` entry per routed net in the sibling `.kicad_pro`, so KiCad's Board Setup and native DRC see the widths the copper actually uses instead of a flat `Default` without regex/wildcard pattern spillover. GND and power rails land in their own dedicated classes. Hand-authored classes, patterns and edited netclass assignments are preserved (stricter-wins merge on the floor keys); re-running route is idempotent. A missing `.kicad_pro` or a read-only output directory is a non-fatal warning, exactly like the sidecar writes.
