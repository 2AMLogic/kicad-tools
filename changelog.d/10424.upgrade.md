- **Review blank LCSC fields before uploading a JLCPCB assembly BOM** (Issue #10424).
  Wire solder landings and rows whose catalogue match cannot verify the required
  MPN, package, tolerance or power may now export with a blank LCSC field.
  Find the designators and reasons under `Unmatched parts` in the export's
  LCSC enrichment summary. Use `--no-auto-lcsc` to review the BOM with automatic
  matching disabled. For parts the assembler should fit, assign a verified LCSC
  code in the schematic or project spec, or set the schematic MPN and re-export
  with matching enabled so an exact, compatible catalogue part can be selected.
