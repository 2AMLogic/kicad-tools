- **`kct route` no longer reports SUCCESS when the pour completion loop raises**
  (Issue #10710). An exception inside the KiCad-oracle completion loop used
  to be logged as a warning and leave the stranded-pour count at `0`, so the
  run printed its SUCCESS banner and exited `0` with every pour link still
  open. The stranded-pad count is now reported as unknown: the run exits `10`
  (UNVERIFIED) with the exception in its banner. The board is still saved and
  nothing is raised out of the stage.
