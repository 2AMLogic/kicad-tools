- **Datasheet pitch extraction no longer truncates a measurement with a letter attached** (Issue #10362). `e=1.27mmA` or `pitch 1.27B` used to report a 1.0 mm pitch (or a dropped 0.0 for sub-millimetre values) as a measurement; such a token is now treated as ambiguous, the search continues to a later valid pitch, and otherwise the inferred package default is used.
