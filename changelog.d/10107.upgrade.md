- **Re-verify ambiguous legacy readiness receipts before sign-off** (Issue #10107). If an older receipt cannot identify the editable PCB among routed boards, snapshots, or historical copies, run `kct readiness <editable-pcb> --mfr <manufacturer> --verify` and pass the new verification receipt to `kct tapeout-sign-off --readiness`. Use `--sch <root-sheet>` when schematic discovery is ambiguous.
