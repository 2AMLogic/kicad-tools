- **Pandoc PDF reports show a project name's markup characters literally** (Issue #10641). `render_pdf_pandoc` now hands the `title`, `subtitle` and `author` cover scalars to Pandoc as literal `--metadata` values, as it already did for `date`, instead of letting it read them from the YAML block as Markdown. A board named `R&D <b>x</b> *i* _j_.kicad_pcb` keeps its angle brackets and asterisks on the PDF cover instead of losing the tags and gaining italics, and a `date` that does not start with `Rev ` is treated the same way.
