- **`kicad_project.zip` delivers one project KiCad can open** (Issue #10108). `kct export` and `kct readiness --generate` package the board, its rules, the project file and the root sheet under the root sheet's basename, so KiCad opens the schematic and the board together and native schematic parity runs on the extracted board. A revisioned `board_v07` board or a `board_routed.kicad_pcb` checked against `board.kicad_sch` is delivered as `board.kicad_pcb`, `board.kicad_pro` and `board.kicad_dru`; a `VERSION.md` member records the working revision and which checked file each member came from, and the packaged project names itself correctly in `meta.filename`. The renaming happens in the archive only: the checked files are not modified, `kct readiness --verify` still binds every member to its source, and a `VERSION.md` kept beside the board travels with the project.
