- **`kct drc` no longer counts informational findings as warnings** (Issue
  #10650). A DRC report whose only findings are `info` exited 2 under
  `--strict` and export's DRC preflight read WARN, because the parsed report,
  the `kct drc` counts and the `--mfr` gate each derived "warning" from "not
  an error". Board 04's report (five warnings and six informational findings)
  reached its manufacturing manifest as `DRC passed with 11 warning(s)`.
  `DRCReport.warning_count` now counts only `warning`-severity findings and
  informational ones are listed separately: an `INFO (informational,
  non-gating)` section and `Infos:` count in the table, an `Infos` column in
  `--format summary`, `summary.infos` in `--format json`, and a new
  `DRCReport.infos` / `info_count` accessor. `kct stitch`'s post-stitch DRC
  counts the same way. Errors, real warnings, unconnected items, schematic
  parity and waivers gate exactly as before.
