- **`kct pcb reinforce --clear` and `--replace` check the destination wire records before removing anchors or parallel copies** (Issue #10419). An unreadable reinforcement sidecar, including a directory or a dangling symlink, makes the command exit 1 and report the path before writing the PCB or copying project files. With `-o`, the check uses the output board’s sidecar. Readable symlinks and boards without sidecars remain supported.
