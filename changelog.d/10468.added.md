- **`kct export` can attach revision-bound simulation evidence** (Issue #10468). A board may declare cases in `<board>.simulations.json`; each pairs a deck with a producer-supplied result and an inclusive bound. The bundle README and `manifest.json` report `pass`, `out_of_range`, `stale`, `missing` and `invalid` per case, separately from native DRC, and package the evidence with hashes. Nothing is executed, and boards without a declaration export unchanged.
